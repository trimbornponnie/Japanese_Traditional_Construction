# Japanese Traditional Construction

A detailed rulebook of Japanese traditional timber construction: the historical construction manuals, systems of measure and proportion, timber and tools, joinery (継手 *tsugite* and 仕口 *shiguchi*), pins and wedges, structural frames, roofs, bracket sets, building types, finish carpentry, assembly sequence, repair and modern code context.
